CSS Colors

CSS supports different ways to represent colors.

  1. Color Keywords
  2. Hex Color Code
  3. RGB
  4. RGBA
  5. HSL

1. Color Keyword

Example: color: darkred;

2. Hex Color Code

Example: color: #0BEE0B;

3. RGB Color

Example: color: rgb(76, 125, 59);

4. RGBA Color

RGBA is RGB with opacity.

5. HSL Color

Example: color: hsl(130, 61%, 44%);
